FEATURED PROJECT

        
My Second DevOps Project — Flask on AWS EC2

        
Building and deploying my first production Flask application, from local development to a live server on AWS EC2. Every stage below is a real step from that deployment, not a mockup.


        

          

            
01 · Architecture

            
Browser → Nginx → Gunicorn → Flask → HTML/CSS/JS

            
Learned how a request travels through the entire deployment stack, from the browser down to the rendered page.

          

          
        


        

          

            
02 · Project structure

            
Organized the project following Flask best practices — a clean split between routes, templates and static assets.

          

          
        


        

          

            
03 · Deploy to AWS

            
Deployed the application on an Ubuntu EC2 instance, with security-group rules opened for SSH and HTTP.

          

          
        


        

          

            
04 · Reverse proxy

            
Configured Nginx as a reverse proxy in front of Gunicorn, so the app answers on port 80 instead of being exposed directly.

          

          
        


        

          

            
05 · Process management

            
Managed the application with systemd so it restarts on failure and starts on boot, and confirmed it locally on port 5000 before putting Nginx in front.

          

          
        


        

          

            
06 · Version control

            
Pushed the project to a public GitHub repository, with commits tracking each stage of the build.

          

          
        


        

          

            
07 · Live demo

            
The result runs live at ibrahimsaad.ddns.net.
